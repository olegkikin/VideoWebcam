FFmpeg
- Project: https://ffmpeg.org/
- Windows binary provider: https://www.gyan.dev/ffmpeg/builds/
- Used as a separate executable. The downloaded essentials build contains GPL components; its license and build details are distributed in licenses/FFmpeg.txt and licenses/FFmpeg-build.txt.
- The bootstrap download follows the provider's release alias. Record the executable version and SHA-256 when shipping a particular package. A local build manifest is generated by the media test script.
- Before redistributing FFmpeg binaries, comply with that build's license, including providing the matching complete corresponding source and build material as required. This development folder is not a prepared public FFmpeg source distribution. Alternatively, ask recipients to obtain their own FFmpeg build from the provider.
